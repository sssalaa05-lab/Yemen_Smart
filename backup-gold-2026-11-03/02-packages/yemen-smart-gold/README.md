# 🥇 حزمة «يمن سمارت — الإصدار الذهبي» (Yemen Smart · Gold Edition)

نقل ثيم الذهب من داشبورد FinGPT Gold إلى منصة **يمن سمارت** (نظام تداول MT5).

## محتويات الحزمة

| الملف | الغرض |
|---|---|
| `gold-admin.css` | ⭐ ملف Override كامل (14 قسماً) يقلب اللوحة إلى ثيم الذهب — يعمل بالحقن الفوري أو بالإضافة إلى `globals.css` |
| `GOLD_PROMPT.md` | برومبت جاهز للصق في محادثة المشروع هناك (يشمل التصميم + إصلاح خطأ Jan 1970 + النصوص المشوهة) |
| `before-after/before.png` | اللوحة قبل (فاتحة متضاربة) |
| `before-after/after-gold.png` | اللوحة بعد الحقن الحي — النتيجة الفعلية على الموقع الحقيقي |

## استخدام سريع (تجربة فورية بدون تعديل كود)

1. افتح المنصة واضغط F12 (أدوات المطور) → تبويب Console.
2. الصق محتوى السطر التالي (يحمّل الثيم ويحقنه):
   ```js
   const s=document.createElement('style');s.textContent=await (await fetch('FILE:gold-admin.css')).text();document.head.appendChild(s)
   ```
   أو انسخ محتوى `gold-admin.css` كاملاً والصقه بعد `const s=document.createElement('style');s.textContent=\`` مع الإغلاق `\`;document.head.appendChild(s)`.
3. التحول فوري — وأزلته بإعادة تحميل الصفحة.

## التثبيت الدائم في مشروع يمن سمارت

- **الأسرع**: أضف محتوى `gold-admin.css` في نهاية `src/app/globals.css`.
- **الأصح هندسياً**: استخدم `GOLD_PROMPT.md` — يوجه المساعد هناك لتطبيق المتغيرات في shadcn
  واستبدال أصناف sky/slate/blue من المصدر (خالد، بدون !important).

## ما يغطيه الملف (مفصّل على مكونات المنصة)

شريط إخباري علوي · هيدر sticky · تنقل أفقي بتبويب نشط متوهج · شريط جانبي shadcn
(عنوان ذهبي متدرج + عنصر نشط ذهبي) · جداول (رأس ذهبي متدرج، صفوف داكنة، hover) ·
شارات شغّالة/مقفلة · قوائم منسدلة وحقول بتركيز ذهبي · هالة علوية · شريط تمرير رفيع ·
طبقة التقاط لأصناف Tailwind بمعدّل الشفافية (`bg-sky-50/80`، `bg-sidebar`...).

## ملاحظات اكتُشفت أثناء الفحص الحي

1. **خطأ التواريخ**: جدول الحسابات يعرض `Jan 1970 21` — timestamp بقيمة 0 (epoch).
   يُفحص تحويل التاريخ في كود الجدول (ثوانٍ مقابل ميلي ثانية، أو قيمة فارغة → new Date(0)).
2. **تسميات مشوهة** في التنقل الأفقي (مثل «تناقل السضوص») تحتاج مراجعة نصية.
3. الخط الحالي IBM Plex Sans Arabic موجود أصلاً في المشروع — يُضاف فقط IBM Plex Mono للأرقام.
