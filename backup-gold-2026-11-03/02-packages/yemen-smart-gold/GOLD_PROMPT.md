```text
طبّق على منصة «يمن سمارت» (Yemen Smart Trading) إعادة تصميم كاملة بثيم «طرفية الذهب» الداكن — نفس الهوية، لا ألوان أخرى:

【الهدف】
تحويل اللوحة الحالية (خلفيات سماوية فاتحة bg-sky-50، رؤوس جداول كحلية slate-800، لمسات زرقاء/خضراء متضاربة) إلى هوية موحدة: أسود دافئ + ذهبي عنبري، طابع طرفية تداول فاخرة.

【الخطوط】
- أبقِ IBM Plex Sans Arabic للنصوص (موجود أصلاً) وأوزان 400/500/600/700.
- أضف IBM Plex Mono (400/500/600) لكل الأرقام والحسابات والتواريخ والأزمنة داخل الجداول، مع font-variant-numeric: tabular-nums و dir="ltr" لخلايا الأرقام.

【لوحة الألوان — طبّقها كمتغيرات shadcn في وضع داكن دائم】
--background: oklch(0.16 0.01 85)   /* أسود دافئ #0f0d08 */
--foreground: oklch(0.93 0.012 85)  /* أبيض دافئ #ebe7df */
--card: oklch(0.2 0.012 85)  --popover: oklch(0.19 0.012 85)
--primary: oklch(0.78 0.145 82)     /* الذهبي #e5ad34 */
--primary-foreground: oklch(0.18 0.03 82)
--muted: oklch(0.25 0.012 85)  --muted-foreground: oklch(0.66 0.02 85)  /* #989285 */
--accent: oklch(0.28 0.025 82)  --destructive: oklch(0.704 0.191 22.216)
--border: oklch(1 0 0 / 9%)  --input: oklch(1 0 0 / 13%)  --ring: oklch(0.78 0.145 82 / 55%)
--sidebar: oklch(0.19 0.012 85)  --sidebar-accent: oklch(0.28 0.025 82)
--radius: 0.625rem
وضع className="dark" على html (وضع داكن دائم).

【الاستبدال الإلزامي في كل المشروع】
- bg-sky-50/80/100 و bg-white و bg-slate-50..200 → خلفيات داكنة دافئة (#0f0d08 للصفحة، #12100a للأقسام، #191610 للبطاقات).
- bg-slate-800/900/950 (رؤوس الجداول والأزرار الداكنة) → #24211b مع حدود ذهبية شفافة.
- كل حدود border-sky-200 / border-slate-800 → rgba(245,158,11,0.18).
- كل النصوص الزرقاء/السماوية النشطة (text-sky-600..900، text-blue-*) → ذهبي text-amber-300 #fcd34d أو #fbbf24.
- النصوص الرمادية الداكنة فوق فاتح → #ebe7df (أساسي) و #a8a29e (ثانوي) و #78716c (ثالثي).
- الأخضر emerald يبقى فقط للدلالة على النجاح/التشغيل (شارة «شغّالة»، نبض البث الحي) — لا يستخدم كلون هوية.

【بصمات الثيم الإلزامية】
1) الشريط الإخباري العلوي: خلفية rgba(12,10,6,0.96) + حد سفلي ذهبي rgba(245,158,11,0.15) + نقطة النبض ذهبية #fbbf24 + نص الخبر #fde68a.
2) الهالة العلوية: طبقة fixed أعلى الصفحة h-80 بـ radial-gradient(ellipse at top, rgba(245,158,11,0.12), transparent 62%).
3) الهيدر العلوي sticky: خلفية داكنة شفافة + backdrop-blur-md + حد سفلي ذهبي؛ أزرار الهيدر (Platform Administrator، مؤسسي) بأسلوب زجاجي داكن بحد ذهبي خفيف.
4) شريط التنقل الأفقي: العناصر غير النشطة #a8a29e، وعند hover تتحول #fde68a مع خلفية ذهبية 8%؛ التبويب النشط: نص #fbbf24 + خط سفلي ذهبي متوهج (text-shadow: 0 0 14px rgba(245,158,11,0.35)).
5) الشريط الجانبي (shadcn sidebar): خلفية #16130e، العناصر #a8a29e، العنصر النشط خلفية ذهبية 12% ونص ذهبي، أسماء المجموعات #78716c، عنوان «يمن سمارت» بتدرج ذهبي: linear-gradient(120deg,#fde68a,#f59e0b 45%,#d97706) مع background-clip:text.
6) الجداول: الرأس بتدرج ذهبي خفيف (linear-gradient to left, rgba(245,158,11,0.14), rgba(245,158,11,0.05)) ونص #fde68a؛ الصفوف بفواصل rgba(255,255,255,0.06) و hover ذهبي 5%؛ أكواد الحسابات ($S...) بالذهبي #fcd34d وبخط Plex Mono.
7) القوائم المنسدلة والحقول: خلفية rgba(255,255,255,0.04)، حدود rgba(255,255,255,0.13)، وعند التركيز حد ذهبي + هالة rgba(245,158,11,0.18).
8) شريط تمرير رفيع 8px بمقبض #44403c.
9) شارات الحالة: «شغّالة» خضراء شفافة rgba(5,150,105,0.18) بنص emerald-400، «مقفلة» رمادية شفافة، وأي شارة مؤسسية/مميزة ذهبية bg-amber-500 text-amber-950.

【إصلاحات وظيفية أدمجها مع إعادة التصميم】
1) التواريخ في جدول الحسابات تعرض "Jan 1970" — قيمة timestamp = 0 (epoch). راجع تحويل التاريخ: غالباً الحقل يُقرأ بالثواني بينما يُعامل كميلي ثانية أو العكس، أو القيمة فارغة فتُحوَّل new Date(0). اعرض «—» عند غياب التاريخ بدل Jan 1970.
2) بعض عناصر التنقل الأفقي نصوصها مشوهة/مبتورة (مثل «تناقل السضوص»، «تنتاح التداول») — راجع التسميات واكتبها صحيحة.
3) وحّد اتجاه الأرقام: كل خلية رقمية dir="ltr" داخل صف RTL.

【ملاحظة تنفيذية】
يمكن تطبيق كل ما سبق فوراً بحقن ملف gold-admin.css المرفق (مكتوب بمحددات تناسب مشاريع Tailwind+shadcn بمعدّلات الشفافية مثل bg-sky-50/80 و bg-sidebar). الأفضل: ادمجه في globals.css ثم نظّف الأصناف من المصدر حسب الاستبدال الإلزامي أعلاه.
```
